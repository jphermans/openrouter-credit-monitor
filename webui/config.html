OpenRouter Management Key
Required for the account balance. Create one at openrouter.ai/settings/keys (choose a provisioning/management key). Stored server-side only and never shown again after saving.
OpenRouter API Key optional
Used only for key-level usage info (label, usage, spending limit) from GET /api/v1/key. The monitor works without it.
Refresh interval
How often the WebUI asks the plugin backend for a fresh balance.
Low-credit warning (USD)
Show a “Low” badge and a warning notification at or below this remaining balance.
Critical-credit warning (USD)
Show a “Critical” badge and an error notification at or below this remaining balance.
Show balance in WebUI
Display the persistent OpenRouter indicator in the sidebar.
